# 005: 永続化と認証を本実装に差し替える

## 目的
- MVP のメモリ保存と擬似 Cookie 認証を、本番向けの構成に移行する。

## やること
- データストアを PostgreSQL + Prisma などへ移行する。
- ユーザー / 場 / スレッド / 投稿 / 反応を永続化する。
- 認証を Auth.js などへ差し替える。
- 既存の `store.ts` と `identity.ts` のIFを崩さず移行する。

## 完了条件
- サーバ再起動後もデータが残る。
- ログイン状態が安定している。
- 現行UI/APIが大きく壊れない。

## 依存
- 既存MVP

## 備考
- これは機能追加ではなく、プロダクト化の基礎工事。
